# PPBF Web Portal (Next.js)

Stakeholder portals for the PPBF 25-capability platform.

## Routes
- / : Home + nav
- /reports : Grant/Impact Reporting (Cap 16)
- /brand : Creative & Brand (Cap 17)
- /ledger : Continuity Ledger (Cap 22)
- /athlete/dashboard : Athlete Self-Service (Cap 13)
- /readiness : Readiness + Safety Gate (Cap 11)

Run:
cd apps/web
npm install
npm run dev
