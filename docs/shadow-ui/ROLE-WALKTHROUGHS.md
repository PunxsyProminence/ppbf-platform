# Role walkthrough scripts (staging/production)
**Tagline:** OBSERVE. DECIDE. EXECUTE. REPEAT.  
**Room DNA:** each step must feel like the correct room.

## Athlete
1. /public  → office/public
2. /athlete/sign-in → entry
3. kiosk check-in → floor
4. /athlete/dashboard → floor
5. progression or drills → floor
6. /shadow if athlete allowed → night
7. logout

## Coach
1. /login Bell → entry/office
2. coach landing → floor
3. Morning Read → floor
4. decision loop or hold → floor/clinic
5. sports medicine → clinic
6. /notices → office

## Parent
1. login → entry
2. /parent/dashboard → office warm
3. safety → office/clinic-adjacent care
4. consent → office
5. progression-visibility → office

## Board
1. login → entry
2. /board or seat → board
3. compliance-monitoring → board (counts only)
4. escalation-monitoring → board
5. /shadow → night **deny minimal only**

## Admin
1. login → entry
2. /admin/people → office
3. /admin/pin → office
4. /admin/customize → office
5. /admin/escalations → clinic

Log: WALK / role / step# / PASS|FAIL / room felt / note
