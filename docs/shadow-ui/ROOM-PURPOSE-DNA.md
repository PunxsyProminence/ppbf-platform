# ROOM PURPOSE DNA — no two rooms feel alike
**Date:** 19 Aug 2026 · Grok · Jason: each room must feel like its purpose  
**Tagline:** OBSERVE. DECIDE. EXECUTE. REPEAT.

---

## Law
Every screen inherits **exactly one** room.  
If two screens feel interchangeable, the room DNA failed — fix tokens/chrome, not more wallpaper.

---

## The six rooms (must stay distinct)

### 1. Front Office — `.room--office`
| | |
|--|--|
| **Purpose** | Records, families, roster, notices, admin desk work |
| **Feel** | Plank wall, desk lamp, paper forms, riveted cards |
| **Motion** | Forms, tables, invite buttons, “Nobody here yet” |
| **Copy voice** | Clerk / front desk — clear, procedural, kind |
| **Allowed chrome** | Notice banners, photo slots, chalk, roster badges |
| **Forbidden** | Clinic green, night telemetry, board wainscot, heavy bag floor drama |
| **Easter eggs?** | Yes — chalk/notices/photos. Not medical drama. |

### 2. Gym Floor — `.room--floor`
| | |

| **Copy voice** | Coach in the corner — short, direct, kid-first |
| **Allowed chrome** | Chalk, WordsOnTheWall, CLEARED badges, floor cards |
| **Forbidden** | Board tables, file cork, clinic green, night admin console |
| **Easter eggs?** | **Primary home** |

## Differentiation checklist
| Question | Fail if |
|----------|---------|
| Could this screen be mistaken for another room? | YES → wrong room tokens |
| Are eggs/chalk present where forbidden? | YES → remove |
| Does board show chat or athlete detail? | YES → delete |
