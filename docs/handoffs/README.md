# Handoffs

Dated, addressed handoff briefs for specific other AI working sessions on
this repo, produced out of the 2026-08-17 capability-network audit.

## Files

| File | Addressed to | Scope |
|---|---|---|
| `HANDOFF_RESEARCH.md` | Research account | Questions no amount of coding can close: Act 153/SafeSport clearance vocabulary, travel waiver contents, whether LEGACY-READINESS can be validated or should be retired, `assessment_protocols` reference data, the four blocked formula-registry entries, and whether the platform's existing youth-safety thresholds are correct. |
| `HANDOFF_VISUALS.md` | Visuals account | The visual layer of the platform: refusal-state stamps for six new safety gates, the portrait-review console redesign, the six unstyled Capability Console pages, seven locker gear icons, and gym building illustrations. |

## How these are used

The owner points the named session at its specific `HANDOFF_*.md` file
directly. That session works its listed items as bounded draft PRs per its
own "Working agreement" section in that file. This directory is the durable
record of what was handed off and when — it is not itself an instruction
source for ordinary implementation sessions. `AGENT_KERNEL.md`'s read path
does not include `docs/handoffs/`; a session reads a file here only when
specifically pointed at it.
