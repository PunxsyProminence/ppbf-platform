**DOC-123, this week:**

> Week 3: Set Before Punch - Preparation Discipline
> Week 3 instills the critical discipline of establishing proper position before initiating offensive actions. Monday introduces deliberate set position checks before any punch. Tuesday stabilizes the set-check-punch sequence through repetitive drilling. Wednesday applies setting mechanics under coach-called offensive opportunities. Thursday maintains set discipline during rapid combination work and fatigue. Optional punch introduction for Week 3: uppercut mechanics in shadow boxing or light controlled introduction, available if earned through consistent setting before punching. Punches must be removed if student throws without setting, rushes the preparation phase, or demonstrates inconsistent position checks.
